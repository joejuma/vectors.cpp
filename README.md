# Vector (Library)
By Joseph Juma

## About
A library implementation for 32-bit floating-point 2D and 3D Euclidean vectors.

## Usage
1. Add the headers to your project.
2. Include the corresponding header where you want to use the structure.
3. Create a vector of the given type.

## Files

| File | Description |
| ---- | ----------- |
| `Vector2f_struct.h` | 32-bit floating-point 2D Euclidean vector structure. |
| `Vector3f_struct.h` | 32-bit floating-point 3D Euclidean vector structure. |

## LLM Disclosure
-	LLMs were used to generate the three additional binary operator
    implementations from a hand-written addition operator. So, every
    human-written `+` was passed to an LLM which generated the
    corresponding `-`,`*` and `/` variants.

-	LLMs were not used for any other aspect of this code.
